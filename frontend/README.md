# Frontend (React)

Initial frontend scaffold for VolleyReel.

## Pages included
- Dashboard
- Tournaments
- Teams
- Players
- Matches
- Tournament Analytics
- Reports
- Leaderboards

## Structure
- `src/pages/*` page-level features
- `src/components/layout/*` shared app shell (sidebar/topbar)
- `src/routes/*` route configuration
- `src/services/*` API client placeholders
